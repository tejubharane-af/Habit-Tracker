# 🔥 Daily Habit Tracker Web App

A clean, modern daily habit-tracking web application built using **Python**, **Streamlit**, and **SQLite**. It helps users build consistency by tracking daily habits, maintaining streaks, and visualizing weekly progress.

## ✨ Key Features
- **Add & Delete Habits:** Easily create new daily habits or remove existing ones.
- **Automated Streak Calculation:** Dynamically tracks consecutive days of habit completion using Python's `datetime` logic.
- **Weekly Progress Tracker:** Visualizes consistency across the week (`M T W T F S S`) with color-coded indicators.
- **Persistent Storage:** Uses **SQLite** to store habits and completion logs locally.
- **Responsive Card UI:** Styled with custom CSS for a clean, mobile-friendly dashboard experience.

## 🛠️ Tech Stack
- **Language:** Python
- **Frontend / Framework:** Streamlit, Custom CSS
- **Database:** SQLite3

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Habit-Tracker
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   streamlit run app.py
   ```
